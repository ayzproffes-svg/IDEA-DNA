# 90-second hackathon demo

## Prepare

Run the app and open `/explore`. For a live AI demo, configure Supabase and an AI provider, run the demo seed in a development project, and sign in with your own account. Keep two tree nodes ready to select. Without credentials, explicitly introduce demo mode and show the existing sample synthesis; do not claim a new AI request succeeded.

## Script

**0–15 seconds — The problem**

“Great ideas appear in discussions every day. But a useful suggestion gets buried, context disappears, and the people who moved the idea forward lose credit. IdeaDNA gives those ideas a place to grow.”

**15–30 seconds — Discover**

“Here is the living network. These are three demonstration projects, with attributed contributions. Let’s open the low-cost water monitor. The root is a problem worth solving. Each branch is a different mind making it more practical.”

**30–50 seconds — Contribute**

Click the sensor node, then Build on this idea.

“I can add field calibration as an improvement. It becomes a branch with my name, its parent, and a contribution history. Another collaborator sees it through realtime updates.”

**50–75 seconds — Synthesize**

Select the sensor and solar nodes, then Synthesize.

“Now connect two strengths. The synergy engine proposes a solar-powered monitoring station, explains how it works, names the constraints, and suggests the next experiment. The blueprint stays connected to both original contributors.”

**75–90 seconds — Close**

Open the synthesis details and point to its sources.

“This is a traceable path from discussion to invention. Every question has a place. Every contributor keeps their credit. IdeaDNA: a little more possible, together.”

## Demo fallback

If the provider is rate limited, acknowledge the error and open the seeded synthesis blueprint. The sample is labeled and remains usable. For a two-browser realtime demonstration, use the connected development workspace; browser-local demo data is intentionally not shared across devices.
