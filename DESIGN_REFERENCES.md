Research: October 22–23, 2026. FreeFrontend was the primary reference source. No example code, assets, or testimonials were copied. The graph's behavior is implemented with React Flow; the visual metaphor and product language are original to IdeaDNA.

## Visual system

- Charcoal-green canvas, quiet forest surfaces, mint primary actions, and pale text. Light mode uses warm off-white, dark green text, and a deeper green action color.
- System sans-serif for fast loading and crisp UI, paired with Georgia italic for editorial headings. No remote font dependency or tracking request.
- Consistent 6–10 px radii, fine separators, and generous margins. Shadows are confined to floating graph nodes and dialogs.
- Standard lucide icons. SVG graph previews use native vector elements, not stock imagery or generated bitmap assets.
- Purposeful motion: hover elevation, new-node entrance, synthesis progress, and reduced-motion support.
- Mobile: compact sidebar, stacked cards and forms, a retained pan/zoom canvas, and full-width dialog content.
- Accessibility: semantic headings and landmarks, named form controls, visible focus, keyboard graph inspection, modal focus management, and status/error announcements. Native selects keep filters usable on small screens.

## Implementation decisions

Tailwind v4 runs through PostCSS. Shared tokens live in the global component stylesheet. The Button uses the standard shadcn/ui composition approach (Radix Slot, CVA variants, clsx, tailwind-merge); `components.json` is supplied for extending the library. The visual design intentionally avoids copying glassmorphism, saturated gradients, and decorative dashboard widgets from examples.
